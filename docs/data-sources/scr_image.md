# samsungcloudplatformv2_scr_image (Data Source)

Get details of a Docker image in a Container Registry.

## Example Usage

```terraform
provider "samsungcloudplatformv2" {
}

data "samsungcloudplatformv2_scr_image" "image" {
  id = var.id
}


output "image" {
  description = "The image data source."
  value       = data.samsungcloudplatformv2_scr_image.image
}


variable "id" {
  type        = string
  default     = "ENTER YOUR RESOURCE'S ID"
  description = "The ID of the Docker image."
}
```
