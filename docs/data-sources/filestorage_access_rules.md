# samsungcloudplatformv2_filestorage_access_rules (Data Source)

Lists all access rules for a File Storage Volume. This data source is read-only and includes rules managed by external automation (e.g., Kubernetes Auto Scaling). Do NOT use this data source output with `for_each` to create `filestorage_access_rule` resources — doing so will re-introduce the forced reconciliation problem.

## Example Usage

```terraform
provider "samsungcloudplatformv2" {
}

data "samsungcloudplatformv2_filestorage_access_rules" "all" {
  file_storage_id = var.file_storage_id
}


output "all_access_rules" {
  value = data.samsungcloudplatformv2_filestorage_access_rules.all.access_rules
}


variable "file_storage_id" {
  type    = string
  default = "ENTER YOUR RESOURCE'S FILE_STORAGE_ID"
}
```
