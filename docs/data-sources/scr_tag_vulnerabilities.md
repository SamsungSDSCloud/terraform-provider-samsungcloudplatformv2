# samsungcloudplatformv2_scr_tag_vulnerabilities (Data Source)

Get a list of vulnerabilities (CVEs) for a specific tag in a Container Registry.

## Example Usage

```terraform
provider "samsungcloudplatformv2" {
}

data "samsungcloudplatformv2_scr_tag_vulnerabilities" "vulnerabilities" {
  tags_id = var.tags_id
  size    = var.size
}


output "vulnerabilities" {
  value = data.samsungcloudplatformv2_scr_tag_vulnerabilities.vulnerabilities
}


variable "tags_id" {
  type    = string
  default = "ENTER YOUR RESOURCE'S TAGS_ID"
}

variable "size" {
  type    = number
  default = 100
}
```
