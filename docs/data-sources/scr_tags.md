# samsungcloudplatformv2_scr_tags (Data Source)

Get a list of tags for an image in a Container Registry repository.

## Example Usage

```terraform
provider "samsungcloudplatformv2" {
}

data "samsungcloudplatformv2_scr_tags" "tags" {
  image_id = var.image_id
  page     = var.page
  size     = var.size
  sort     = var.sort
}


output "tags" {
  value = data.samsungcloudplatformv2_scr_tags.tags
}


variable "image_id" {
  type    = string
  default = "ENTER YOUR RESOURCE'S IMAGE_ID"
}

variable "page" {
  type    = number
  default = 0
}

variable "size" {
  type    = number
  default = 10
}

variable "sort" {
  type    = string
  default = "modified_at:desc"
}
```
