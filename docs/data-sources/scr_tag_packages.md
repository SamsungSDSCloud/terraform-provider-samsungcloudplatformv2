# samsungcloudplatformv2_scr_tag_packages (Data Source)

Get a list of packages for a specific tag in a Container Registry.

## Example Usage

```terraform
provider "samsungcloudplatformv2" {
}

data "samsungcloudplatformv2_scr_tag_packages" "packages" {
  tags_id = var.tags_id
  size    = var.size
}


output "packages" {
  value = data.samsungcloudplatformv2_scr_tag_packages.packages
}


variable "tags_id" {
  type    = string
  default = "ENTER YOUR RESOURCE'S TAGS_ID"
}

variable "size" {
  type    = number
  default = 100
}
```
